Data and code for "White-faced capuchins (Cebus capucinus imitator) exhibit selectivity for stone tools" by Meredith K.W. Carlson, Brendan J. Barrett, Evelyn del Rosario-Vargas, Tamara Dogandzic, Margaret C. Crofoot, and Nicolas Zwyns
This repository contains the raw data and data cleaning R code used for the analyses in the manuscript.
The raw data are included as a csv file, "Capuchin_Tool_Surveying_2025-01.csv".
The R code used for data mangement is included as an R script, "01_kobo_cleaning_code_FINAL.R".
